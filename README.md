\# 🤖 NextWave CRM Onboarding Agent

\### Agents for Humans Hackathon 2026 — Professional Agents Track



An AI-powered agent that helps small businesses and nonprofits 

set up Salesforce CRM automatically using AWS Strands Agents + Claude AI.



\## 🎯 The Problem

Small businesses waste weeks figuring out how to configure 

Salesforce CRM. NextWave Tech Studio coordinates this manually 

for clients every day — this agent automates that process.



\## ✅ The Solution

A conversational AI agent that asks 5 smart questions and 

generates a fully customized Salesforce implementation plan 

in minutes — not weeks.



\## 🏗 Architecture

\- \*\*Frontend:\*\* React chat UI

\- \*\*Backend:\*\* Flask API (port 5000)

\- \*\*AI Engine:\*\* AWS Strands Agents SDK + Claude AI via Bedrock

\- \*\*Logic:\*\* Multi-file Python modules for onboarding + CRM recommendations



\## 🚀 How to Run



\### Backend

pip install flask flask-cors strands-agents strands-agents-tools

python app.py



\### Frontend

cd crm-agent-ui

npm install

npm start
